## 📌 Application: College Management System (CMS)

### Tasks Implemented:
- **Task (a):** Problem statement and main entities (`Departments`, `Students`, `Professors`, `Courses`, `Enrollments`) with attributes.
- **Task (b):** Relational database schema with data types and constraints.
- **Task (c):** Primary Keys (PK), Foreign Keys (FK), and Cardinalities (1:N, M:N).
- **Task (d):** Interactive visual ER Diagram in HTML (`er_diagram.html`) using Mermaid.js.
- **Task (e):** SQL `CREATE TABLE` DDL script, executed & verified in SQLite (`college_management.db`).

```bash
python db_documentation_generator.py
```

1. `er_diagram.html` - Open in browser to view the interactive ER Diagram.
2. `college_management.db` - SQLite database containing verified tables and records.
